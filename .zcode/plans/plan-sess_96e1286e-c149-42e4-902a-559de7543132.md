# learnrussian — Russian Course App (A2 → C1): Implementation Plan

**Stack**: Next.js 16.2.6 (already scaffolded: App Router, Turbopack, Tailwind v4, shadcn "base-nova"/Base UI), **Drizzle ORM + mysql2** on the provided MySQL (`learnrussian` DB, `DATABASE_URL` used verbatim), **Better Auth** (drizzleAdapter, email/password), **ts-fsrs** for spaced repetition. Next 16 conventions honored: `proxy.ts` (not middleware), `await params/searchParams/cookies()`, no `cacheComponents` (default caching model), Server Components for reads / Server Actions for writes, every action re-verifies the session.

## 1. Database

### 1a. Dictionary import (`openrussian_dump.sql`, 612 MB)
The dump is double-mangled (re-saved as UTF-16LE with CP437 mojibake — verified byte-exact recoverable) and targets `openrussian`, not `learnrussian`.

`scripts/repair-dump.py` (single streaming pass):
1. decode UTF-16LE → encode CP437 per char (log unmappables) → decode UTF-8 → write UTF-8
2. rewrite `CREATE DATABASE`/`USE \`openrussian\`` to target `learnrussian` (or strip both)
3. strip `LOCK/UNLOCK TABLES` lines (shared-host privilege risk)
4. re-split INSERTs >256 KB (largest is 1.02 MB — `max_allowed_packet` safety)
5. keep `FOREIGN_KEY_CHECKS=0` intact (table order requires it)

Import via mysql CLI (or Node/mysql2 statement-streamer fallback); pre-check skips import if `words` already has ~90,586 rows. Post-verify: words 90,586 · words_forms 1,715,824 · sentences 358,885 · translations 206,113 · sentences_words 1,654,047; spot-check Cyrillic is clean (`сказать`, no mojibake).

What this unlocks: 90,586 words with CEFR `level` (sparse) + frequency `rank` (1–59,653) + `type`; **62 form types** = full noun sg/pl case tables (`ru_noun_sg_gen`…), full adjective grids + short forms + comparative/superlative, full verb conjugation (`ru_verb_presfut_sg1..pl3`, past m/f/n/pl, imperatives, active/passive participles, gerunds); stress stored as ASCII apostrophe (`сказа'ть`) → displayed via combining acute U+0301 (сказа́ть), typed answers compared against `form_bare`; 358,885 CEFR-tagged sentences with English translations; `words_rels` (synonym/antonym/related); per-word audio URLs. Dictionary tables are **read-only** for the app; all app tables prefixed `lr_`. Words lacking level/rank are placed via rank band + curation; words without an EN translation or audio are filtered / TTS-fallback.

### 1b. App schema (drizzle-kit push, same DB)
- Better Auth tables: `user`, `session`, `account`, `verification` (CLI-generated, folded into drizzle schema).
- `lr_profiles` (userId PK): dailyGoalXp (default 20), timezone, streakCount, lastActiveDate, currentLevel ('A2'|'B1'|'B2'|'C1'), placementDone.
- `lr_lesson_progress` (userId, lessonId) PK: status, bestScore, attempts, completedAt.
- `lr_grammar_mastery` (userId, topicId): score 0–100, reps, lastPracticed.
- `lr_srs_cards`: id; unique (userId, wordId, kind) — kind ∈ recog|produce|cloze|audio; FSRS fields (state, due, stability, difficulty, step, reps, lapses), suspended.
- `lr_review_logs`: cardId, rating 1–4, reviewedAt, scheduledDays.
- `lr_exercise_attempts`: userId, exerciseId, type, correct, response JSON, createdAt.
- `lr_daily_activity` (userId, date) PK: xp, minutes, lessonsDone, reviewsDone — streak source of truth.

## 3. Curriculum — 46 units, ~225 lessons
Unit = 4–5 lessons + unit test; level exam gates next level; test-out (≥80%) unlocks anything. Lesson ≈ 10–15 min, pass ≥70%: **Theory** (2–4 grammar blocks: rule in plain English + inflection table + 3–5 examples with audio/translation) → **Vocab** (8–12 words) → **Practice** (8–12 exercises, ≥50% DB-generated on the lesson topic) → **Summary** (score, XP, SRS enqueue, quiz-renderer export). Pass ≥70%. Topic IDs (`a2-u03-genitive-sg`) drive mastery tracking and targeted drills.

**⚠ Notes requirement (per your addition): every lesson's grammar notes are self-contained, simple, and concise — rule, pattern table, worked examples, and a "common trap" tip — so the user has everything needed to attempt that lesson's practices without any external reference.** Notes follow a fixed checklist: (1) what it is, (2) the forms/endings table, (3) when to use it, (4) 3–5 examples, (5) common trap. Practices never test anything the notes above them haven't covered.

**A2 — 12 units** (foundations rebuilt first, since grammar is weak)
1. Present tense system: -ать/-ять/-еть/-ить, -ова-/-ева-, consonant mutation (писать→пишу), core verbs, question words
2. Nominative/Accusative/Prepositional sg: gender, animacy, в/на/о + Prep
3. Genitive sg: possession (у меня есть), нет + G, quantities, после/до/без/для/около/у
4. Dative sg: indirect object, age (мне 20 лет), нравиться, помогать/звонить, к/по, dative impersonals (надо, можно, нельзя, пора)
5. Instrumental sg: с + I, instruments, быть/стать/работать/казаться + I, свой
6. Past & future: -л/-ла/-ло/-ли, буду + inf, time expressions
7. Aspect I: pairs (делать/сделать), process vs result, prefixes по-/с-/на-/за-/вы-, aspect in past/future
8. Adjectives sg all cases; plurals nom/gen; possessives & этот declension; colors, clothes
9. Motion I: идти/ходить vs ехать/ездить, unidirectional vs multidirectional, пойти/поехать
10. Motion II: prefixes при-/у-/в-/вы-/под-/от-/за-/до-/пере-/про-, йд/ех stem switching
11. Numerals & time: 1–1000, 1–4 declension + noun agreement, clock, dates, age
12. Reflexive -ся intro; imperatives (sg/pl/-те, давай); modals должен/нужно/следует — **A2 exam**

**B1 — 12**: 1 Plurals all 6 cases + gen-pl rules/fugitive vowels · 2 Adjective/pronoun plural declension + adjectival nouns · 3 Motion III: носить/возить/вести + prefixes, idiomatic motion · 4 Aspect II: suffix pairs (-ыва-/-ива-, -ну-), prefixed pairs, infinitive aspect after начать/удаться/получиться · 5 -ся verbs full system · 6 Conditional: бы + past, если бы…то бы, polite не мог бы ты · 7 Active participles (-ущ-/-ющ-, -ащ-/-ящ-, -вш-) replacing который · 8 Passive participles (-ем-/-им-, -нн-/-енн-/-т-) + short participles vs short adjectives · 9 Verbal adverbs (-я / -в / -вшись) replacing когда-clauses · 10 Complex sentences: который (all cases), чтобы, когда/пока/до того как/после того как, потому что/так как/поэтому, хотя · 11 Full pronoun declension + negatives + -то/-нибудь/-кое- · 12 Word formation — **B1 exam**

**B2 — 12**: 1 Aspect III semantics (за- ingressive, по- delimitative, от-/про- finitive, по- distributive, iteratives) · 2 Impersonal constructions full range · 3 Passive voice & participle syntax · 4 Verbal adverbs advanced · 5 Complex connectors (несмотря на то что, в то время как, благодаря/из-за того что, зато, тем не менее…) · 6 Indirect speech (ли, что/будто) · 7 Conditionals II: unreal + concessives · 8 Numerals advanced (оба/обе, collective, fractions, approximations, predicate agreement) · 9 Word order & theme/rheme + particles же/ведь/уж · 10 Motion IV: full prefixed grids for carry verbs · 11 Comparatives/superlatives full · 12 Register & style — **B2 exam**

**C1 — 10**: 1 Aspect in infinitives/imperatives + negated infinitives · 2 Academic participle style (-мый adjectives) · 3 Literary verbal adverbs · 4 Advanced subordination (correlatives, clefts, так что, словно) · 5 Modality & evidentials · 6 Word-formation master grid · 7 Formal registers (business/academic/journalistic) · 8 Ellipsis & discourse particles · 9 Idiomatic constructions (не успел…как, стоит…чтобы, чем…тем) · 10 **C1 integrated exam**

Scope cross-checked against the referenced TheLanguageBro fundamentals guide (cases → verbs → aspect → motion → participles/gerunds → syntax).

**Example lesson spec** (`a2/u01/lesson-1`, "Present tense I: -ать verbs"): blocks = (1) endings table я -ю / ты -ешь / он -ет / мы -ем / вы -ете / они -ют rendered from работать's DB forms; (2) spelling rule ы→и after ж/ш/щ/ч/к/г/х; 3 A2-tagged DB example sentences. Vocab: 10 verbs. Practice (10 items): 4 generated conjugation type-ins, 2 form-picker MCQs, 1 DB-sentence fill-blank, 1 matching pronoun↔ending, 1 word-order building, 1 EN→RU short-answer. Exit: 4 SRS cards per word.

## 4. Vocabulary injection
Per-lesson curated word-ID lists, authored by querying `words` by type + rank band + level + topic fit, verified against EN translations. Bands: A2 rank ≤1,500 · B1 1,500–3,500 · B2 3,500–7,000 · C1 7,000–12,000 + curated. 8–12 words/lesson → ≈ A2 550 · B1 900 · B2 1,150 · C1 900 (≈3,500 new words). Word card: accented display, top-2 EN senses, POS, mini forms table, audio (`words.audio` hotlink, `speechSynthesis` ru-RU fallback), 1 level-matched example sentence (auto-joined via `sentences_words`/`sentences_translations`).

**SRS (ts-fsrs; request_retention 0.9, learning steps 1m/10m, max interval 365d)**: lesson completion creates 4 card kinds per word (recognition ru→en; production en→ru typing with Cyrillic keyboard; cloze from the example sentence; audio→word). `/review` = due queue, Again/Hard/Good/Easy, daily cap ≈ goal×2, all grades logged; dashboard shows due count + streak.

## 5. Exercise engine
Internal exercise format = quiz-renderer's 7 types (single, multiple, true-false, short-answer, ordering, fill-blank `{{blank}}`, matching; Markdown text) → everything in-app is exportable verbatim. Two sources:
1. **Authored** per lesson (~6–8 items): theory-check MCQs, translations, case-government matching, word-order building, fill-blank templates.
2. **Runtime-generated** from dictionary forms (infinite practice): conjugation drills, case drills, comparatives, participle/gerund formation, cloze from level-tagged sentences. Typing gets the ported Cyrillic virtual keyboard + translit IME (port of quiz-renderer `lib/translit.ts`).

XP: lesson +10, correct exercise +2, review card +1, unit test +25, level exam +100; streak = any XP on a local calendar day; default goal 20 XP/day (configurable).

## 6. Quiz-renderer compatibility (supplementary)
`lib/quiz-export.ts` serializes any lesson/practice session into quiz-renderer's exact `QuizJsonSchema` (validated in tests against a ported copy of its Zod schema). UI: **"Download quiz for Quiz Renderer"** on lesson summary + `/practice` — the JSON is dragged into quiz-renderer `/quizzes/new` (its only import path; it has no POST API). No cross-DB writes, no shared auth (separate DBs by design). Same 0–100 scoring bands for consistency.

## 7. App surface
- `/` → redirect · `/login` · `/register`
- `/dashboard`: continue-lesson card, due-reviews badge, streak + daily-goal ring, weak topics
- `/learn`: level tabs → unit grid with progress/locks · `/learn/[level]/[unit]`: lesson list + unit test · `/learn/[level]/[unit]/[lesson]`: lesson player
- `/review`: SRS session · `/practice`: drill hub (topic/case/verb/aspect pickers → generated sets + export)
- `/placement`: 30-item authored adaptive test (A1→B2 sampling) → recommends start level
- `/dictionary`: search (bare/accented/EN translation LIKE; filters type/level/rank) · `/dictionary/[wordId]`: full forms tables, senses, audio, synonyms/antonyms, sentences
- `/progress`: XP chart, mastery heatmap by grammar topic, vocab counts by level, 7-day review forecast
- `/settings`: daily goal, theme, stress-mark display, translit keyboard toggle, reset progress
- API: `/api/auth/[...all]`, `/api/dictionary/search`; all other mutations via Server Actions.

## 8. Content format
`content/curriculum/{a2,b1,b2,c1}/uNN-slug/{unit.ts, lesson-N.ts, test.ts}` typed by `lib/curriculum/types.ts`. Static TS imports → typechecked + versioned, no CMS. Authored A2 → B1 → B2 → C1. Unit tests, 4 exams, and placement are authored as internal quiz JSON.
