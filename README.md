# learnrussian — русский шаг за шагом

A structured Russian course from **A2 to C1**: grammar-first lessons, vocabulary
injected per CEFR level, spaced repetition, and unlimited generated drills —
built on the [openrussian.org](https://openrussian.org) dictionary dump
(90,586 words, 1.7M inflected forms, 359k CEFR-tagged sentences).

## Stack

- **Next.js 16.2.6** (App Router, Turbopack, Tailwind v4, shadcn `base-nova`)
- **Prisma 6 + MySQL** — app tables (`user`, `session`, `lr_*`) managed by
  `prisma db push`; openrussian dictionary tables are **read-only**, their
  models were generated by `prisma db pull` (see `prisma/schema.prisma`)
- **Better Auth** (email/password, Prisma adapter, 30-day sessions with cookie cache)
- **ts-fsrs** spaced repetition (request retention 0.9)

## Getting started

```bash
yarn install
yarn db:generate && yarn db:push   # sync app tables
yarn dev                           # http://localhost:3000
```

## Course structure

4 levels (A2/B1/B2/C1) × 12/12/12/10 units, each unit = 2–5 lessons + unit test
(≥80% unlocks the next unit) + level exam. Every lesson follows the same loop:

1. **Notes** — self-contained grammar blocks (rule → table → examples → trap)
2. **Vocab** — 8–12 dictionary words (accented forms, audio, senses)
3. **Practice** — authored exercises + drills generated live from `words_forms`

Content lives in `content/curriculum/{a2,b1,b2,c1}/uNN/index.ts`, typed by
`lib/curriculum/types.ts`. Vocabulary references are bare Russian words,
resolved to dictionary ids at runtime (`lib/curriculum/content.ts`).

## Key directories

| Path | What |
|---|---|
| `lib/curriculum/` | types, content loaders, grading, locks, drill generators, XP |
| `lib/russian.ts` | stress-mark rendering (апостроф → ударение), answer normalization |
| `lib/review.ts`, `lib/srs.ts` | FSRS review batches and scheduling |
| `components/practice/` | exercise runner, review runner, Cyrillic keyboard/translit |
| `app/actions/` | server actions: progress, practice, placement, settings |
| `content/curriculum/` | all lesson content |
| `scripts/` | dump repair (`repair-dump.py`), import, DB/vocab verification |

## Quiz-renderer compatibility

Any lesson/practice set can be downloaded as JSON matching the sibling
quiz-renderer app's `QuizJsonSchema` (7 question types) — drag the file into
quiz-renderer → `/quizzes/new`. Schema ported in `lib/quiz-schema.ts`.

## Conventions

- Dictionary tables are never written by the app; app tables are prefixed `lr_`
- Stress in stored text is an ASCII apostrophe after the vowel (`сказа'ть`);
  render through `withStress()` (safe for mixed English text)
- Typed answers compare via `normalizeRu` (lowercase, ё→е, apostrophes stripped)
- Next 16: `proxy.ts` (not middleware), `await params/searchParams`
